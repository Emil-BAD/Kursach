# Dormitory Management Platform

Backend-платформа для управления жизненным циклом студенческого общежития: учет жителей, распределение по комнатам, проверки чистоты, финансовые операции, новости, события, контроль нарушений и административные процессы. Проект реализован как масштабируемый API на основе FastAPI и SQLAlchemy и рассчитан на использование в реальной среде управления общежитием.

## О продукте

Это backend-сервис для цифровизации работы общежития: от регистрации пользователей и управления помещениями до контроля финансов, санитарных проверок и коммуникации с проживающими.

Система покрывает ключевые бизнес-процессы университетского или коммерческого общежития:

- учет студентов и сотрудников
- привязка к общежитию, блоку и комнате
- учет нарушений и дисциплинарных мер
- контроль соблюдения санитарных норм
- работа с новостями и событиями кампуса
- платежи, счета, баланс и пополнения
- удобная административная панель на основе RBAC

Платформа построена так, чтобы быстро масштабироваться под несколько корпусов, разных ролей пользователей и сложную бизнес-логику управления жилым комплексом.

## Проблема, которую решает продукт

В большинстве общежитий процессы всё ещё управляются по разрозненным инструментам: таблицы Excel, ручные проверки, бумажные журналы, сообщения в мессенджерах и хаотичный учет оплат. В результате:

- сложно контролировать состояние комнат и жильцов
- администрация теряет время на рутинные операции
- нет единой базы данных по оплатам и нарушениям
- штрафы, проверки и коммуникации ведутся разрозненно
- студенты не получают прозрачного доступа к актуальной информации

Данный проект создает единый цифровой слой для работы с жилым фондом и процессами жизнедеятельности общежития.

## Ключевой функционал

### 1. Управление пользователями и доступом

- регистрация и аутентификация через JWT
- разграничение доступа по ролям: студент, администратор, комендант, председатель совета, член совета и др.
- авторизация на уровне прав и ресурсов через RBAC
- профиль пользователя с привязкой к общежитию, блоку и комнате

### 2. Управление общежитием

- каталог общежитий и корпусов
- привязка комнат, жильцов и руководителей
- структура данных для управления жилым фондом

### 3. Финансовый модуль

- учет баланса пользователя
- создание и оплата счетов
- история платежей и начислений
- пополнение средств и выгрузка финансовой истории
- поддержка административного контроля по статусам платежей

### 4. Санитарный контроль и дисциплина

- оценка чистоты комнат
- лог истории проверок
- привязка проверяющего к конкретной комнате
- учет нарушений и типологий нарушений

### 5. Коммуникации и события

- новости и объявления для студентов
- события и календарь активности общежития
- скоординированные уведомления по доменам: общежитие, блок, комната, глобально

### 6. Сервисные запросы и административная работа

- заявки на обслуживание и ремонт
- работа с обращениями и статусами
- структурированные административные процессы

## Архитектурная идея

Проект построен по принципу модульной backend-архитектуры:

- API layer — HTTP-эндпоинты и валидация входных данных
- service layer — бизнес-логика и сценарии использования
- repository layer — работа с базой данных и запросами
- data model layer — ORM-модели и сущности домена
- security layer — JWT, роли, права, зависимости доступа

Такой подход делает систему поддерживаемой, масштабируемой и понятной для дальнейшего развития в продукт.

- Python 3.11+

- CORS и безопасные API-настройки
- Docker-ready deployment model

## Роли и доступ

Система поддерживает несколько категорий пользователей:

- Student — обычный студент
- Admin — администратор платформы
- Commandant — комендант общежития
- Council President / Council Member — представители студенческого совета
- Sanitary commission roles — участники и руководители санитарной комиссии

Доступы управляются централизованно через RBAC-механизм, без рассеивания проверок по коду.

## Основные доменные модули

- `users` — профиль пользователей, привязка к общежитию
- `dormitory` — общежития, корпуса, комнаты
- `cleanliness` — санитарные проверки и оценки
- `user_violations` — нарушения и дисциплинарные меры
- `news` — объявления и новости
- `calendar` — события, календари и планирование
- `payments` — финансы, счета и пополнения
- `service_requests` — заявки и обращения
- `reports` / `residence` — аналитика и справки

## Бизнес-ценность

Проект позволяет перевести процесс управления общежитием из ручного режима в цифровую, контролируемую, масштабируемую платформу:

- снижение нагрузки на администрацию
- прозрачная история действий и оплат
- единый источник данных по общежитию
- контроль соблюдения правил и санитарных норм
- возможность дальнейшего развития продукта до уровня полноценного SaaS/ERP для жилого фонда
